Mojo 正式开源了，我装好跑通了

发表于2026-08-19|更新于2026-08-22|技术教程
|浏览量:

今天 Hacker News 热榜上挂着一条消息：Mojo 语言正式开源了。就是那个宣传语喊了很久的「Python 语法、C 语言速度」的语言，作者是 Chris Lattner——LLVM 和 Swift 的作者，编译器圈子里分量很重的人。以前它只开放 SDK，源码一直捏在手里，这次全放出来了，背后的公司 Modular 现在归高通（Qualcomm）旗下。

一句话说清它是什么：一门能直接跑 Python 代码、但按原生速度执行的语言，主要面向 AI 和高性能计算场景，不是给写业务脚本的人准备的。

我趁热装了一个，把过程记下来，想尝鲜的直接照着来。

先说我装完的结论：安装比想象中顺，一条命令，没有依赖地狱；但别被宣传里的性能数字冲昏头，那些倍数都是挑过的特定场景。现阶段它的意义就是「尝鲜 + 感受」，指望它替换 Python 干活，生态还早。

Mojo 和 Python 到底是什么关系

简单说：Mojo 是 Python 的超集，大部分 Python 代码它能直接跑，也能调用 Python 的库（通过互操作接口），所以你不是从零开始。区别在写法：想快的部分用 fn 加类型标注，让它编译成机器码；其余地方还是你熟悉的 Python 手感。

我的判断

  • 适合谁：想尝鲜的程序员；对性能敏感又不想离开 Python 生态的人；对编译器技术好奇的人。
  • 不适合谁：只想写脚本、做数据分析的，Python 够用，没必要折腾。
  • 生态现状：库远不如 Python 全，很多坑要自己趟，上生产要慎重。
  • 但有一点是实的：真想优化的那段代码，不用换语言、不用学 C++，用 Mojo 重写就行。这个价值是长期存在的，跟它开源不开源没关系。

想直接试的话，把第 4 步那段代码贴进 playground 就能跑，不用装任何东西。开源第一天，趁热玩吧。
