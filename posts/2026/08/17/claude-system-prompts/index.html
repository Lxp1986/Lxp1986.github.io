Claude 把 claude.ai 的系统提示词公开了，我抄了几条到自己的 Agent

发表于2026-08-17|更新于2026-08-22|技术
|浏览量:

昨晚刷 Hacker News，首页第一名挂着 Anthropic 的链接，五百多分，点进去是 claude.ai 系统提示词的官方文档页。Claude 其实一直把网页版和 App 用的系统提示词公开在文档里，按模型、按日期更新，能一路翻到 2024 年。这次又火一轮，大概是 Opus 5 的新版本被大家拿去逐行分析。

先用人话解释：系统提示词就是每次对话开始前，藏在后台给模型看的那份说明书——告诉它今天几号、你是谁、该怎么说话、什么不能碰。你平时跟 Claude 聊天，你发的第一条消息前面，其实垫着这么一大段。

文档地址是 platform.claude.com/docs/en/release-notes/system-prompts。有个细节值得注意：这套提示词只管 claude.ai 网页和 App，不作用于 API。调 API 的时候，模型只认你自己传的那份 system prompt，官方这套跟你的代码没有关系。

我翻了一遍 Opus 5 那份

光 Opus 5 这一份就三万多词，比我自己写过的所有配置加起来都长。整体分两大块：行为规则（claude_behavior）和一堆机制说明。行为规则里又分产品信息、默认姿态、拒绝规则、语气格式、立场中立、心理健康几个小节；机制部分包括记忆文件系统、结束对话工具、Artifacts 存储、MCP 工具建议、历史对话搜索这些。

挑几条我印象深的：

  1. 默认姿态是帮忙。原文大意：只要帮忙不会造成具体而严重的伤害，就默认帮；擦边、假设、开玩笑、让人不舒服的问题，都够不上拒绝的标准。
  2. 回复保持简短，结论先行，免责声明要短；每条回复最多追问一个问题；用户不先爆粗，模型就不说脏话。
  3. 最让我在意的一条：明确要求少用 “genuinely”、”honestly”、”straightforward” 这类词，理由是诚实是默认值，反复强调反而显得不真诚。AI 味一大半就是这么来的，国内对应版就是”说实话””老实讲””毫不夸张”。
  4. 立场中立：用户让模型阐述某个立场时，给的是”支持者会怎么辩护”，不是模型自己的观点，最后还得补上对立面的看法。

别整份抄

claude.ai 那份是给 Anthropic 全家桶写的：产品介绍、记忆文件系统、Artifacts 存储全依赖自家基础设施。整份贴到自己的 agent 里，模型会去调用不存在的工具，或者一本正经地介绍你根本不用的产品。挑行为规则抄就够了。另外它更新得勤，抄的时候看一眼日期，别拿半年前的版本当最新。
