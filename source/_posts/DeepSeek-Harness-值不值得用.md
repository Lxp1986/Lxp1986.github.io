先给结论：这工具现在还不适合拿来干正事。想尝鲜、想学它架构的可以装，指望它稳定出活，再等几个月。

## 几个不错的地方

官方出品，模型和框架是一套，配合比第三方拼出来的顺。MIT 开源，代码随便改。不绑死模型，DeepSeek、OpenAI、Claude 都能接。工具免费，API 也便宜，晚上还半价。

## 几个让我犹豫的地方

还是预览版，官方自己都写了「会有破坏性变更」，今天能用的功能过俩月可能就变了。配置概念有学习门槛，装起来简单，用好不简单。生态刚起步，出了问题能搜到的答案少。12 万星是热度，不是稳定。

## 跟其他几个比

| 工具 | 出品方 | 开源 | 印象 |
|---|---|---|---|
| DeepSeek Harness | DeepSeek | ✅ | 可定制、便宜，但还年轻 |
| Claude Code | Anthropic | ❌ | 省心、生态成熟，要订阅 |
| Codex CLI | OpenAI | ✅ | 跟 GitHub 配合最好 |
| Aider | 社区 | ✅ | 极简，只做结对写代码 |

（信息查于 2026-08-16，星数和版本会变。）

## 我的建议

爱折腾、想学 Agent 怎么设计的，现在装，社区正热闹。已经在用 DeepSeek 的，直接上。只想省心出活的，选 Claude Code。要上生产的，等 1.0 再说。
