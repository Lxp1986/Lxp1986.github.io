最近 DeepSeek 开源了一个叫 **DeepSeek Harness** 的工具，发布不到三天 GitHub 上就拿了 12 万多个星，火得一塌糊涂。很多朋友问我：这玩意儿是干嘛的？普通人能用吗？怎么装？

这篇文章就用**大白话**，手把手带你把它跑起来。

## 先搞懂它是什么

一句话：**模型负责「想」，Harness 负责「做」。**

你平时用 AI 聊天，它只能跟你"说"。而 Harness 能让 AI 真正**动手**：自己读你电脑里的文件、改代码、执行命令、调工具，干完一步看结果，接着干下一步，直到把整件事做完。

举个例子：你让它"帮我分析一下这个项目"，它会自己去翻目录、读代码、跑命令，最后给你一份报告——全程不用你操心。

## 第一步：装环境（只需要 Node.js）

Harness 对电脑的要求特别简单，就一个 **Node.js**（版本要 22.19 以上，或者 24）。

到 [Node.js 官网](https://nodejs.org/) 下载最新的 LTS 版安装即可（Windows 直接下一步下一步，Mac 拖进 Applications）。

装好后，打开终端（Windows 按 Win+R 输入 cmd 回车；Mac 打开"终端"），输入下面这行检查有没有装好：

```bash
node -v
```

能显示出版本号（比如 `v22.19.0`），就说明环境 OK 了。

## 第二步：一条命令装上 Harness

继续在终端里输入这一条命令：

```bash
npx @deepseek-ai/dsh web
```

第一次跑会自己下载安装，等个几十秒，看到它提示启动成功后，用浏览器打开这个地址：

```
http://127.0.0.1:3080
```

看到界面，说明装好了。（这条命令会一直开着，别关终端。）

## 第三步：填 API Key，选好工作区

进到网页后，做两件小事：

1. **填 API Key**：点左上角 **Settings → Models**，在 DeepSeek 那一栏填上你的 API Key（去 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请，有免费额度）。填完保存就行，**不用重启**。
2. **选工作区**：点 **Choose workspace**，选一个你想让它干活的文件夹（比如你的项目目录）。**不选的话，输入框是灰的，发不了任务**——这是新手最容易卡的地方。

## 第四步：发第一个任务，看它干活

新建一个会话，把下面这句话复制进去，回车：

> 总结这个文件夹的结构，说明它是个什么项目，用到了哪些技术，如果我是一个新人该从哪里开始看。

你会看到它开始"动手"：翻文件、读代码、跑命令，最后吐出一份总结。恭喜，你已经会用 Harness 了。

## 它能帮你干哪些活？（三个真实例子）

### 例子一：分析代码仓库

就是上面那个任务。项目越大，它越能帮你省时间——看不懂的老项目，直接丢给它"讲讲这个仓库在干嘛"。

### 例子二：每周自动写周报

不想手动写周报？让它每周一早上自动汇总你上周的代码提交，生成一份周报。把下面这段存成一个脚本（比如 `weekly.sh`），再用系统自带的定时任务（cron）设成每周一早上跑：

```bash
#!/bin/bash
cd /你的项目目录
git log --since="1 week ago" --pretty=format:"%h %an %ad %s" --date=short > /tmp/gitlog.txt
dsh --profile headless "根据下面的 git 提交记录，帮我写一份中文周报，按主题归类，每类给一两句总结，用 markdown 格式。提交记录：$(cat /tmp/gitlog.txt)"
```

### 例子三：定时巡检

让它每小时帮你查一次：磁盘满没满、网站挂没挂、依赖有没有更新。有问题就提醒你。这个要开一个叫 schedule 的插件，稍微进阶一点，感兴趣的可以翻官方文档。

## 小白常见问题

**Q：我填了 Key 还是报错？**
八成是 Key 填错地方了。确认是在 Settings → Models 里填的，而且 Key 复制全了（别漏字符）。

**Q：它会不会乱动我电脑上的东西？**
默认只允许它在"工作区"这个文件夹里改东西，其他地方只读。所以工作区最好单独建一个文件夹，别直接用你的重要目录。

**Q：Windows 和 Mac 都能用吗？**
都能，环境要求就是 Node.js，装法一样。

**Q：要钱吗？**
工具本身免费开源。要钱的是你调的 API（DeepSeek 有免费额度，用完才收费，价格挺便宜）。记得它有个"峰谷定价"：晚上和周末用更便宜，大批量任务可以排到晚上跑。
