上一篇我们把它装好跑起来了。这篇不聊技术细节，就聊一个实在的问题：**这玩意儿值不值得你花时间用？**

## 它到底是个啥（再重复一遍，很重要）

**模型负责"想"，Harness 负责"做"。** 它让 AI 不再只是"聊天"，而是能真正帮你干活：读文件、改代码、跑命令、自动完成一整个任务。

## 它好在哪（优点）

1. **官方出品，模型和工具是一家人**：DeepSeek 自己的模型 + 自己的框架，配合最默契，官方跑分就是在它上面测的。
2. **免费开源，随便改**：MIT 协议，代码、文档全开放。想改哪一层都能改。
3. **不绑死一家模型**：想用 DeepSeek 也行，OpenAI、Claude、自己搭的网关，都能接，随时切换。
4. **便宜**：工具免费，加上 DeepSeek 的 API 本身是同类里最便宜的，晚上用还半价。

## 它有什么坑（缺点，说真话）

1. **还是"预览版"，不稳**：官方自己都说了"会有破坏性变更"——今天能用的功能，过俩月可能就变了。**别急着上生产环境**。
2. **配置概念有门槛**：虽然装起来简单，但想用好它（插件、profile、各种配置层），学习曲线不低，对纯小白不够友好。
3. **生态刚起步**：第三方的插件、教程、踩坑分享，跟老牌工具比还差得远。出了问题，能搜到的答案少。
4. **star 数 ≠ 成熟度**：12 万星是"关注度"，不是"稳定性"。大家是冲它热度来的，不是冲它稳定来的。

## 跟别人比，谁更适合你

| 工具 | 出品方 | 开源吗 | 一句话总结 |
|---|---|---|---|
| **DeepSeek Harness** | DeepSeek | ✅ MIT | 可定制性最强、最便宜，但还年轻 |
| **Claude Code** | Anthropic | ❌ 闭源 | 最省心、生态最成熟，但要订阅 |
| **Codex CLI** | OpenAI | ✅ 开源 | 跟 GitHub 配合最好 |
| **OpenHands** | 社区 | ✅ MIT | 偏研究、多 Agent 协作 |
| **Aider** | 社区 | ✅ 开源 | 极简，只做"结对写代码" |

（以上为 2026-08-16 的公开信息，星星数和版本会变，以官方为准。）

## 结论：谁该用，谁先别急

**适合你现在就用的，是这几类人：**

- 爱折腾、想学 AI Agent 怎么设计的（现在社区最热闹，正是学习的好窗口）
- 已经在用 DeepSeek 模型的（官方同款，配合最好）
- 预算敏感、想找便宜又开源方案的

**先别急着用的，是这几类人：**

- 只想"省心出活、不想折腾"的 → 选 Claude Code，装完登录就能用
- 要拿它干正事、上生产的 → 等它出 1.0 或生态沉淀一两个月再说
- 只想要个"陪写代码"的小工具的 → Aider 更轻

**一句话总结**：Harness 是块好料，架构设计确实漂亮，但现在是"潜力股"不是"即战力"。**想尝鲜、想学习，现在上；想稳定出活，再等等。**
