笔电合盖。

Wi‑Fi 断一下。系统一休眠。

你那边 Telegram 还在等回信，定时任务卡在半分钟前那一步，博客构建跑到一半——全停。

所以我把 agent 挂在家里那台一直开着的 Mac mini 上。

不是 mini 比笔电聪明。是它不睡觉。

![一台合盖笔电，旁边一台常亮的小主机；一根线伸向手机气泡](/img/mac-mini-vs-laptop-sleep.png)

## 我现在怎么挂的

Hermes 装在 Mac mini 上。出门发一句 Telegram，它在家里跑完再回我。这点站内横评那篇写过，不展开装法。

博客发布也常走这台：本机有仓库、有 node，构建完再推 GitHub。笔电那台最近经常离线，我不敢拿它当唯一真相。GitHub 上的 `main` 才是权威——本地落后就先快进对齐，别用旧副本去盖远端。

Grok Bot 另说。它自带云端常开电脑，杂事、网页后台、邮件那些，我仍丢给它。跟 mini 上的 Hermes **有重叠**：远程派活、挂机、定时，两边都能干。我暂时两头留着，还没想好砍哪边。

Codex 写代码多半还在手头这台笔电或云端会话里。长跑、收消息、半夜触发——尽量不绑笔电。

## 为什么不挂笔电

合盖即休眠。这是默认，也是坑。

你以为「接电源就不睡」。不一定。合盖策略、蓝牙外设、Wi‑Fi 掉线，都能让长任务默默死掉。你人在工地，手机上催一嘴，家里笔电在包里睡觉。

出门要带的是笔电。agent 要的是「人走了机器还在」。这两件事别绑死在同一台硬件上。

笔电还要出差、现场拍照、临时改表。合盖、换网络、进电梯，对挂机进程都不友好。

![合盖＝断线：任务条停在约 60%，手机气泡还在转圈](/img/mac-mini-lid-kill.png)

## 挂 mini 我换来什么

**稳。** 插电、有线或稳定 Wi‑Fi、不随身晃。进程挂了至少还能看一眼，不是「包里那台不知死活」。

**远。** Telegram 一条指令进去，回执出来。工地信号烂的时候，异步比盯着笔记本屏幕现实。

**分工清楚。** 笔电＝人在场的工作面。mini＝人不在场还要继续的那一层。博客构建、Hermes 网关、长一点的脚本，我倾向丢后者。

## 我付出什么

电费。24 小时小主机，不是空调，但也不等于零。我没逐月抄表对比，体感就是「能接受的固定开销」。

风扇和灰尘。小机器塞柜子里，夏天要记得透气。别捂死。

更新和排障自己扛。Hermes 升版本、网关掉了、某个模型 Key 过期——没人替你值夜班。横评里写过：灵活的代价是第二份维护工作。挂 mini 只是把这份工作固定在一个地址，不是取消它。

安全。机器上有 API Key、有登录态。磁盘加密、系统更新、别把端口乱暴露到公网——这些我只点名，不写步骤，也不贴路径。

![插座、小主机、手机三点一线；电费小票只是淡淡一笔](/img/mac-mini-always-on-cost.png)

## 和「官方云电脑」怎么处

Grok Bot 的卖点之一就是常开云端机。家里再挂一台 mini，看起来像重复建设。

我的分法很土：

- 要登录一堆网页后台、懒得自己点的 → Grok Bot
- 要碰本机文件、本机浏览器以外的长脚本、我自己维护的 Hermes 技能 → mini
- 纯写代码的短轮次 → Codex / 笔电当面盯

重叠我承认。省事和可控，我还没找到绝对赢家。哪天额度或电费先把我逼急了，再砍。

## 不适合挂 mini 的人

家里不能 24 小时留一台机。

不想自己管进程。

出门几乎不派远程活，笔电合盖也无所谓。

这三种，别被我这篇劝去买主机。云端 agent 或纯笔电当面用，更省心。

我自己是：现场多、异步指令多、还要时不时构建博客——所以 mini 常亮着。

笔电负责我醒着的时候。  
mini 负责我睡着或人在外面的时候。

就这点区别。没更玄的。
