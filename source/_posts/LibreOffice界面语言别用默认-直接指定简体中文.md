我的机器系统语言不是简体中文，LibreOffice 装完一打开，菜单跟着系统走，看着别扭。干活要用的报价书、签证单都是中文文档，菜单不是简体中文，找个「页面样式」都要反应两秒。后来发现这事跟系统语言没关系，纯靠 LibreOffice 自己一个设置就能固定下来。

先说明白原理：LibreOffice 的界面语言默认是「默认」，也就是跟随操作系统。系统是英文就显示英文，系统是繁体就显示繁体。想要简体中文，得把这一项从「默认」改成「简体中文」，别指望改系统语言。

## 设置入口

LibreOffice 里打开设置对话框，macOS 在顶部菜单栏点 **LibreOffice → 偏好设置**，Windows 和 Linux 是 **工具 → 选项**。

左边选项树里找带 Language（语言）字样的那一组。版本不同叫法略有出入：新版叫 **Languages and Locales**，旧版叫 **Language Settings**，展开后进「语言」这一页。

## 关键一步：界面语言别留「默认」

这一页第一栏是「用户界面」（英文 User interface），下拉框里：

1. 把 **默认** 改成 **简体中文 (zh-CN)**。列表里简体中文一般写作「简体中文」，英文界面下显示为 Chinese (simplified)。
2. 顺手把下面的「区域设置」（Locale setting）也选成 **中文（简体，中国）**。这一项管日期、数字、货币的显示格式。不改的话，就算菜单变中文了，Calc 里日期可能还是按英文习惯显示成 `9/7/26`，报价书里要的 `2026年9月7日` 出不来。
3. 点确定，然后**完全退出 LibreOffice 再重新打开**（macOS 按 Cmd+Q）。界面语言要重启后才生效，只关窗口不顶用。

## 下拉里没有简体中文怎么办

说明当前装的这个版本没带简体中文语言。LibreOffice 官方对多语言的支持是分平台的：

- **macOS**：官网下载的 dmg 是多语言版，正常都带简体中文，一般不需要额外装语言包。如果你下拉里找不到，多半是装了来路不明的精简版，去官网 [libreoffice.org/download](https://www.libreoffice.org/download/) 重新下载官方安装包，重装一次就好。
- **Windows**：官网下载页可以选择界面语言，选「中文（简体）」重新下载安装；装完还是没有，就去官网下载对应的简体中文语言包。
- **Linux**：发行版默认只带英文界面，按发行版装语言包。Debian/Ubuntu 系是：

```bash
sudo apt install libreoffice-l10n-zh-cn libreoffice-help-zh-cn
```

装完重新打开 LibreOffice，再按上面的步骤设置。

一个提醒：别去搜「LibreOffice 汉化版」「汉化补丁」。这软件官方本来就支持简体中文，不存在需要第三方汉化的说法。第三方汉化包来源不明，装进去的是什么东西不好说，还有把界面汉化成半中半英的，出了问题官方论坛都没法帮你查。

## 改完怎么验证

重启后看顶部菜单，是不是「文件、编辑、视图、插入、格式」这一排，新建一个 Writer 文档，确认工具栏、右键菜单都是中文。我习惯实际点开几个菜单看过才算数，只看「关于 LibreOffice」窗口里写的语言不算数。

万一界面变中文了但文字显示成方框乱码，那不是语言包的问题，是字体渲染问题，先检查系统里有没有可用的中文字体（macOS 上很少见，Windows 上装过精简系统的会遇到）。

最后说清楚一个容易误会的地方：上面改的是**界面**语言，不影响文档内容，也不会自动把你的文档变成中文；文档默认语言、拼写检查语言在同一个页面的下方单独设置。界面语言管菜单，文档语言管内容，两码事。

弄完这次，以后不管换哪台机器装 LibreOffice，我都是先把这个下拉框从「默认」改成「简体中文」，比改系统语言省事，而且只影响 LibreOffice 自己。
