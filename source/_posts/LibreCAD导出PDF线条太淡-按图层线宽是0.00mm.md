前阵子画一条排洪沟的断面图，LibreCAD 里分好图层、线分粗细，屏幕上看得清清楚楚。导出 PDF 发给监理，对方回一句"线条太淡了，看不清，重新出"。

排查了半天，问题出在 LibreCAD 的"按图层"线宽上。

## 屏幕上的线宽是假的

LibreCAD 屏幕显示的线宽只是示意，跟打印出来是两回事。更坑的是，图层默认的线宽是"按图层（By Layer）"——这在 LibreCAD 里等于 0.00mm。图层分得再细、颜色分得再清，只要线宽没填具体数值，导出 PDF 后线条要么淡得几乎看不见，要么在部分阅读器里直接消失。

搞工程的都习惯按图层分颜色：墙线红色、标注绿色、轴线青色。AutoCAD 时代靠打印样式表（CTB）按颜色映射线宽，画图时根本不用管线宽。LibreCAD 没有这套机制，它只认对象和图层上的 Pen Width（笔宽）属性，默认值就是 0。从 AutoCAD 转过来的人，第一张图基本都会踩这个坑。

## 解决办法：把线宽填成具体数字

两个做法，推荐第一个。

**方法一：图层管理器里设线宽（一劳永逸）**

图层管理器每一行都有 Color / Line Type / Line Width 三列，把线宽从"按图层"改成具体数值：

| 用途 | 线宽 |
|------|------|
| 标注、尺寸、中心线、文字 | 0.18 mm |
| 可见轮廓（墙线、道路边线） | 0.35 mm |
| 剖切线、断面轮廓 | 0.70 mm |
| 图框线 | 1.00 mm |

这是 ISO 制图标准的数值，LibreCAD 官方文档也这么建议。设完把文件另存为模板（.dwt），以后新图直接套，不用每次重新设。

**方法二：全选批量改（补救已经画完的图）**

图画完了不想回图层慢慢改，可以全选批量处理：Ctrl+A 全选 → 菜单 Modify → Attributes（属性）→ Pen Width 填 0.25 → 勾上 "Apply attributes block-deep"（让块里面的对象一起改）→ Apply。

0.25mm 是通用的折中值，保证打印出来清晰。想精细就按上表的数值分层处理。

## 导出 PDF 还有两个坑

1. **先选纸张再导出**：Current Drawing Preferences（当前绘图设置）里把纸张设成 A4 或 A3。不设的话，导出 PDF 有可能是空白页。农村小工程图纸我一般用 A3，1:100 出图，监理看得清，打印店也好打。

2. **打印比例跟线宽无关**：LibreCAD 按 1:1 画图（排水沟 30 米就画 30 米），打印时在打印对话框里输入比例 1:100，或者选适配页面。线宽不受比例影响——设了 0.35mm，打出来就是 0.35mm 粗细，1:1 和 1:100 都一样。这点跟多段线宽度不同：多段线宽度是几何属性，1:100 打印时会跟着缩小，别拿它当线宽用。

## 最后检查

导出 PDF 后别急着发，先放大看一遍：轮廓线是不是明显比标注线粗，图框是不是最粗。屏幕预览靠不住，PDF 里放大看才是真的。另外 LibreCAD 有个草图模式（Draft Mode），开着的时候屏幕连线宽都不显示，检查线宽前先确认它是关着的。

这套整明白之后，我的出图流程固定成了：模板里把图层线宽全设好 → 画图 → 打印预览 → 导出 PDF → 放大检查 → 再发出去。之后再没被监理退过图。
