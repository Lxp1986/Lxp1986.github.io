用 Mac 的人基本都撞到过这个：正干着活，突然弹窗"你的磁盘几乎已满"，然后各种卡、各种存不了。我之前也以为是硬盘买小了，后来才发现，真正常年占着几十 G 不动的，是那些看不到的东西。这篇把我清理的思路和命令记下来，你照着做能腾出一大块。

## 先看明白：到底是啥占了地方

别急着删。打开 **苹果菜单 → 关于本机 → 存储空间**，右边有个"管理"。这里能看到每个类别占了多大，有的人一进来就发现"系统数据"或"文稿"那一栏是最大的，那问题基本就在那。

Mac 的"储存空间管理"会把文件分成几类，你一眼能看清大头在哪。真正让你电脑变慢、报满的，通常是下面这几个。

## 第一招：清"文稿"里的大文件

点开"文稿"，下面会列出下载、桌面、文稿几个文件夹。**按大小排个序**，从大到小看一遍，十有八九能翻出几个超大又没用的东西（比如早就下完的大视频、一堆安装包 dmg）。

命令行的看法更直接，在"终端"里跑这行，把家目录里最大的文件列出来：

```bash
du -sh ~/* ~/Library/* 2>/dev/null | sort -hr | head -20
```

会像这样打印，最上面就是占最多的：

```
4.5G    /Users/你/Library/Developer
2.8G    /Users/你/Downloads
1.2G    /Users/你/Documents
```

看到哪个不想要、又大，直接删。

## 第二招：清 App 缓存（安全，能腾不少）

很多软件会悄悄缓存一堆东西，删了完全不碍事。跑这行，把"缓存"文件夹里每个 App 占的空间按大小排出来：

```bash
du -sh ~/Library/Caches/* 2>/dev/null | sort -hr | head -15
```

确认没问题再删（比如某浏览器缓存、某个图片 App 的缩略图缓存）。缓存删了软件会自动重建，放心。

## 第三招：删本地快照——很多人不知道的大头

这一招我吃了亏才学会。Mac 的"时间机器"会**在本地悄悄存快照**，哪怕你没插外接硬盘，它也可能攒下几十 G，而且你在普通文件列表里根本看不见。跑到终端里看一下：

```bash
tmutil listlocalsnapshots /
```

如果列出一堆带日期的东西（比如 `com.apple.TimeMachine.2026-08-20-123456.local`），就用下面这条把旧快照删掉（会要你输管理员密码）：

```bash
sudo tmutil deletelocalsnapshots 2026-08-20-123456
```

删完再 `tmutil listlocalsnapshots /` 确认那行没了，腾出来的空间会立刻显示出来。这是"系统数据"那一栏总是巨大、背地里最常见的原因。

## 第四招：清空回收站 + 卸载残留

- 回收站：这个最直观，右键"清空"。但注意，**"优化存储"那种自动帮你删的东西别乱点**，有时候删掉的是你还没看完的素材。
- 卸载残留：删 App 别直接拖到废纸篓，很多 App 会在 `~/Library/Application Support` 留一堆配置和数据，几个 G 就是这么攒的。卸载前先看看这个文件夹里对应名字的目录还在不在，一起删掉。

## 顺手检查：系统自身的占用

`/System` 和 `/Library` 底下的东西**别手动删**，那是系统运行需要的，删错了会出大问题。真要清理系统占用的部分，用上面的"第三招"（快照）就够了，别去动系统文件。

## 我用下来的一点判断

1. **清缓存和文稿大文件是最划算的**——安全、见效快、零风险，每次都能腾出不少。
2. **真正的大头往往是快照和"其他/系统数据"**，光删下载文件夹看不到它，得用上面第三招。
3. 别一上来就重装系统或者买新硬盘，先把这几步做了——我身边十有八九的人，做完整理后都发现"其实不用换更大容量的"。

一句话：**先看类别、再清文稿、再清缓存、最后别忘了快照。** 顺序下来，基本能把电脑那个"储存空间不足"弹窗治利索。
