先给结论：**AI 花 token 的大头不在你问了什么，而在它每次回复的废话、每轮重复加载的上下文、以及试错时烧掉的长对话。** 盯住这三处，5 条技巧直接照搬，不用装任何插件。

## token 到底贵在哪

一次 AI 对话的 token = 输入 + 输出 + 思考，三块都要钱（按量计费）或占额度（订阅制）。

| 花钱的地方 | 举例 | 谁在烧 |
|---|---|---|
| 输出的废话 | 寒暄、重复你的问题、过度解释 | 每次回复都在烧 |
| 重复加载的上下文 | 每次新会话都读一遍的长篇记忆文件、工具描述 | 每轮都在烧 |
| 试错 | 任务太大，AI 在超长上下文里反复走弯路 | 一烧烧一串 |

结论：省 token 不是让 AI 变笨，是把**信息密度**提上去。

## 技巧一：让 AI 用电报体回复，砍掉废话

做法：在系统提示或每次任务开头加一句——"回复用简洁风格：结论先行，省略寒暄和重复，技术细节保留完整。"

省在哪：输出 token。这是 caveman 那个"65%"的来源——它的公开做法就是让 agent 用压缩、电报体风格回复，去掉冠词、填充词和客套话，技术细节原样保留。

注意什么：

- 65% 这个数字是 caveman 官方用 10 组 prompt 对比测的**输出 token**降幅（范围 22%–87%），不是整个会话的总账。
- 独立测试没这么乐观：JetBrains 用 82 组配对任务实测，输出只降了 8.5%——因为代码、diff、报错文本不能压缩，能压的只有叙述层。
- 压缩风格本身每轮要多花约 1–1.5k 输入 token（风格指令要每次带上）。任务越短、废话越多，越划算；任务本身已经很精简时可能不赚。
- 以上数字来自 caveman 公开仓库与第三方评测，核对日期 2026-10-04。别信"一键省 65%"的营销话术，看清它省的是哪一块。

## 技巧二：记忆文件写短，每个会话都受益

做法：把每次会话自动加载的记忆文件（比如 CLAUDE.md、AGENTS.md、项目说明）精简到只剩"必须知道"的条目。一条规则只写一遍，删掉解释性废话。

省在哪：输入 token。这些文件每个新会话、每轮都可能被加载，写短一次，之后每轮都省。caveman 公开宣称压缩记忆文件可减少约 46% 输入 token（同样是其官方数据，实际看你自己文件的水分）。

注意什么：别把关键约束删了。省 token 的前提是 AI 不犯错，删掉"不要用什么库"这类硬规则，返工烧掉的更多。

## 技巧三：少贴全文，多给定位

做法：别把整个文件粘进对话让 AI 找。改成给路径加行号、或让 AI 自己用搜索工具定位。需要它读文件时，明确说"只读第 30–80 行"或"先 grep 关键词再决定读哪段"。

省在哪：输入 token。大文件整篇灌进上下文是最常见的浪费，一次几千 token 就没了。

注意什么：AI 的搜索工具有时会漏，关键段落你人工确认一眼再让它动手，比事后返工便宜。

## 技巧四：任务拆小，一次只干一件事

做法：大任务拆成 2–4 步，每步验收通过再走下一步。不要扔一个"把整个模块重构完"的大包让它自由发挥。

省在哪：试错 token。任务越大，AI 在超长上下文里走弯路的概率越高，一次返工烧掉的 token 顶十次正常回复。

注意什么：拆得太碎、每步都等你确认，省的是 token、费的是你的时间。平衡点是"每步结果你能一眼验收"。

## 技巧五：先给摘要，细节按需展开

做法：明确要求"先给结论和 diff 摘要，完整细节我问你要"。这类打法特别适合代码 review、报错排查、方案对比。

省在哪：输出 token。默认情况下 AI 会把所有细节一次倒完，其中一半你根本不会看。

注意什么：涉及删库、发版、改生产配置的操作，别用摘要模式——这种地方宁可让它啰嗦，也别漏关键信息。

## 怎么衡量有没有省下来

不用玄学，看三个数：

| 指标 | 怎么看 |
|---|---|
| 单任务总 token | 很多 CLI（Claude Code、Codex 等）自带用量统计，对比同一类任务优化前后的数字 |
| 输出/输入比 | 输出占比异常高，说明废话多，优先用技巧一、五 |
| 返工率 | 同一任务要返工几次。返工降下来，token 自然降 |

我的做法：挑一周里重复最多的那类任务记一次数，上一条技巧，再记一次。数字自己会说话，不用信任何人的宣称。

## 我的判断

省 token 的本质是**信息密度管理**，跟 caveman 用不用没关系。它的 65% 只是一个极端例子，证明"AI 的废话是真废话"。

另外一个判断：输入侧的优化（技巧二、三）比输出侧更值钱。输出废话你看得见，输入浪费是隐形的——每次会话默默加载的几千 token，一年下来才是大头。先收拾记忆文件，再调回复风格，这个顺序别反。
